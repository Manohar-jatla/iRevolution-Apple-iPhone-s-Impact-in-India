#iRevolution
A Data-Driven Exploration of Apple’s iPhone Impact in India using Tableau
📌 Project Overview
iRevolution is a data analytics project that explores the impact of Apple’s iPhone in the Indian market using interactive visualizations built in Tableau Public and deployed through a Flask-based web application.

The project analyzes:

📈 Annual Revenue Trends

📊 Market Penetration Growth

📱 Model-wise Market Share

🌍 Country-wise Smartphone Share

🗓 Quarterly Performance

📌 KPI Indicators

The final dashboards are published on Tableau Public and embedded into a responsive web UI built using Flask, HTML, and CSS.

##🎯 Objective
To build an interactive, centralized analytics solution that helps stakeholders:

Understand iPhone sales performance in India

Identify high-performing models

Track market penetration growth

Analyze trends across time and regions

Make data-driven business decisions
